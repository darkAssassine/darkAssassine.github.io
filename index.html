Benjamin Köcher

An aspiring Game Engineer.

September 18, 2006 LinkedIn

Hello! I'm an 18-year-old game engineering student at the School for Games (S4G), currently in my fourth semester. While I've tinkered with small coding projects in the past, I began focusing seriously on programming when preparing for the S4G entrance exam in 2023.
I work primarily with C# and Unity, with a strong focus on gameplay programming.
What drives me is seeing code come alive and become interactive - I'm fascinated by the dynamic relationship between code and player, where programming creates responsive experiences that players can engage with directly.
Since starting at S4G, I've worked through three semesters, each featuring a 10-week team project developing small games. These experiences have significantly improved my technical skills and teamwork abilities in practical development environments.
Currently completing my training as a game engineer/programmer, I'm continuously building my knowledge of game development technologies and methodologies. My project work and portfolio can be found in the dedicated Projects section of this site.

Tuuli And The Windy Mountain

Godot, GDScript

1 Semester Itch.io

Tuuli and the Windy Mountain is a charming 2.5D platformer about young Tuuli climbing a mystical mountain. This was a foundational project during which I learned the basics of programming and became familiar with the Godot engine. I implemented core platforming mechanics, including “coyote time,” to create more forgiving and enjoyable player controls. The experience taught me the value of starting with simple concepts before expanding, and how thoughtful constraints can often lead to better game design.
